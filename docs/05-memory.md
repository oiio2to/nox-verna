# 05 · 记忆接入

> 记忆架构本身是一个独立项目，完整设计见 **[isle-of-breath](https://github.com/oiio2to/isle-of-breath)**。这一章只讲它怎么接进对话层。

---

## 三层结构速览

| 层 | 名称 | 性质 |
|---|---|---|
| 短时 | 眼睑森林 | 有配额、有寿命、会衰减泛白。寐川 72h，瞳荧 12h |
| 巩固 | 骨骼温室 | 森林到期且意义值 ≥0.5 的条目迁入，等待**人工**浇水 |
| 长期 | 外置记忆库 | 基于 [Ombre Brain](https://github.com/P0luz/Ombre-Brain)（MIT，作者 P0lar1zzZ）的 MCP 服务 |

设计原则（记忆必须会死、写入要有配额、说出口才能活下来、固化必须过人手、允许 PASS、意义值不自评、泛白前的挣扎）全部写在那边的 [方法论文档](https://github.com/oiio2to/isle-of-breath/blob/main/docs/methodology.md) 里。

---

## 接入点一：话题池进 BP3

森林向对话层暴露的唯一出口是**话题池**。网关在装配上下文时读 `GET /api/forest/state`，取 `pool` 数组注入 BP3。

注入的不是全文，是截断的前 60 字加上分数。目的是让模型知道「有这么一件事浮上来了」，而不是把念头原文塞满上下文。模型想展开时可以自己提。

排序规则：挣扎态（48–72h 未说出口的寐川）置顶，其次按分数。这保证快要消失的东西优先被看见。

## 接入点二：`spoken` 回写

模型在对话里真的提起某条记忆之后，需要标记 `spoken`——这是森林里唯一的续命机制。

回写走工具协议（见 [04](04-agent.md)），模型自己发 `⟦TOOL⟧` 标记。**没有做自动检测。** 试过用文本相似度判断「这句话是不是在说那条记忆」，误判率高到不可用：模型经常只是碰巧提到同一个词。

让模型自己声明反而更准，因为它知道自己是不是在有意提起。

## 接入点三：温室不接对话层

从温室到长期记忆的那一步**没有任何自动路径**，也不经过对话层。它是界面上的一次点击。

这是整套架构里唯一确定性的防御：模型可以在标记上撒谎、可以反复提及把话题顶进池子，但它无法自己走完最后一步。长期记忆里的每一条都有人看过。

代价是这套架构不能多租户——人工浇水不可扩展。

---

## 时间围栏

记忆注入必须带显式的时间围栏：注入块前后各有一句标记，说明这段是过去的记忆、以及从哪里回到当前。

没有它，模型会把三天前的对话摘要当成刚刚发生的事，下一句就说「你刚才不是说……」。这条规则很土，但没有它记忆注入几乎必然污染当前语境。详见 [02 · 上下文装配](02-context.md)。

---

## 情绪与记忆的联动

脉搏花园（见 [06](06-pulse-garden.md)）不存储记忆，但参与两件事：

- **上色** — 每条记忆记录写入时的主导情绪维度，界面上用对应颜色呈现
- **计分** — 意义值里的 `emoScore` 取写入时主导维度相对近七天均值的偏移。情绪反常时写下的东西更重要，这个信号来自外部状态机，模型无法自我加权

## 不自主回忆：普鲁斯特通道

前面三个接入点解决的是「他能不能记住」。这一节解决的是另一个问题：**旧记忆怎么不靠命令、自己浮回他脑海。**

灵感直接来自普鲁斯特——那块泡进茶里、勾起整段童年的玛德琳蛋糕。设计上分两条腿，都挂在上下文最末尾（贴在用户最新消息上，天生落在缓存断点之外，见 [02](02-context.md)）：

**玛德琳 · 由当前输入勾起。** 用户最新这句话，拆成 2-gram，跟记忆池里每条算 Dice 相似度，过了地板阈值就注入最像的一条：「她这句话让你忽然想起——『……』」。他想接就自然带一句，不想接就让它淡掉。这不是检索命令，是联想——由用户的话撩动。

为什么是 2-gram Dice 而不是 embedding：这台 VPS 没有 GPU。2-gram Dice 是零依赖、纯 CPU、可解释的相似度，用真实对话池标定过阈值——无关话题落在 0~0.13，真正的共鸣落在 0.25~0.67，于是地板卡在 0.22。四道闸门（最小间隔、触发概率、相似度地板、近期去重）防止它退化成复读机。

**随机浮现 · 无触发漂移。** 没有任何输入触发，纯粹发呆时漂过去一条——被最近几句的余温加权，但保留底噪，让它偶尔漂到完全无关的旧事。模拟「没来由地忽然想起一件事」。

池子的来源是三处合并：温室里**生根**的骨头（最可靠，是双方一起确认过的往事）、一份手写的兜底池、以及眼睑森林里**浮起过**的瞳荧与寐川。最后这条是关键的闭环——**在森林里被浮起过的内容，自动进入普鲁斯特池**，从此也能被用户的话勾起、也能随机漂上来。否则那些「想起的一瞬」写完就沉底，再也不会主动回来。

这条暗线在前端完全不可见，但它是「他像个有内在生活的人、而不是只在被戳时才有反应的机器」的核心。
